# PromoLibrary — референсы промо Alex

Читает скилл `game-promo-kit` (шаг 0, `promo refs`) при каждом вызове: пересканирует всё, что лежит здесь сейчас.

## Как пополнять
Новая пачка — папка `YYYY-MM-DD <что>` (структура внутри любая). Скрипт понимает:
- **видео** `.mp4/.webm/.mov`: «Превью»/«preview» в имени или пути — hover-превью каталога, иначе — реклама;
- **обложки**: картинки в папке или с именем «Обложка»/«cover»/«icon»;
- **кадры-разбивка**: картинки в папке «Кадры…» с именем `NN — 07.45 — что происходит.jpg` (время в секундах);
- **разбивка текстом**: `<имя видео>.md` рядом с видео или файл `разбивка*.md` / `breakdown*.md` в папке игры;
- **каталог**: строки таблиц в любых `.md`, где упомянута папка игры, становятся описанием игры.
Папка игры = родитель папок «Видео»/«Скриншоты».
- **жанры**: пачка вида `<пачка>/<Жанр>/<Игра>/<Игра>.mp4` + `<Игра>.md`; папка жанра содержит `Паттерны жанра.md` — по нему скрипт узнаёт жанр и поднимает ролики жанра нашей игры. Новый жанр: новая папка + свой `Паттерны жанра.md` + строка в `GENRES` в `scripts/refs.py` и в карте `references/roblox-genres.md`. Пример — `2026-11-24 Roblox промо по жанрам/` (35 роликов, 11 жанров, общий файл `Паттерны Roblox-промо.md`).

`_index/` — служебный кэш скрипта (можно удалить). Чужие ролики — только для анализа, в наши материалы не попадают; в git (CloudRules) библиотека не синхронизируется.
