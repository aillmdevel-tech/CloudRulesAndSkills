# Экономия контекста GameFactory

1. Веди один связный этап в одном чате. Для нового этапа обнови краткий `docs/PROJECT_STATE.md` со ссылками на решения, тесты и отчёты. В длинных старых файлах сначала смотри актуальный блок и заголовки.
2. Сначала обрабатывай видео, дампы, большие JSON и логи скриптами. Передавай нужные таймкоды, измерения, ошибки и пути к полным данным. Выделяй подагенту только независимую работу, где требуется интерпретация.
3. Сборку, smoke и модератор запускай последовательно с `scripts/qa-brief.sh` из корня игры. Скрипт сохраняет полный лог, возвращает короткий статус и при ошибке ограниченный хвост. После актуальной production-сборки smoke использует `--no-build`. Состав проверок и критерии сохраняются.
4. Читай код по символам, совпадениям и диапазонам. Профильные скиллы вызывай автоматически по стадии. Для работы с живой сценой используй Blender MCP.
5. В `/context` смотри объём окна, в `/usage` квоту и кэш. Для сравнения конфигураций держи одинаковыми модель, задачу, папку и набор проверок. Записывай объём контекста и расход отдельно.
