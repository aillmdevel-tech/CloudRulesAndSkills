# Проверка первой минуты (часть проверки B и каждой сборки MVP)

Цель: доказать, что за 60–120 с новый игрок понимает фантазию, делает главное действие, видит результат в мире и видит следующую цель — без подсказок агента.

## Автоматическая часть
`npm run first-minute` (шаблон `templates/autotest/first_minute.py`, ставится вместе с автотестом):
1. Чистый профиль браузера (без сохранения), прод-сборка, 1280×720, звук в лог.
2. Сценарий первых действий из `tools/first_minute.actions.json` (клики, клавиши, удержания — как сделал бы новичок, без телепортов и dev-команд).
3. Кадры на 1, 3, 10, 20, 30, 45, 60, 90, 120 с → `tools/out/first_minute/` + лист `sheet.jpg`.
4. События воронки из `window.__game.funnel` (если подключена, [FUNNEL.md](FUNNEL.md)): когда случились `first_action`, `first_result`, `first_reward`, `next_goal_seen`.
5. Время до первого кадра игры (загрузка) и до первого действия.

## Холодный взгляд (агент без контекста)
После скрипта ведущий агент запускает сабагента, который видит **только** `sheet.jpg` и не знает ТЗ. Промпт:
> Это кадры первых двух минут браузерной игры, подписаны секунды. Ответь коротко по кадрам: 1) Что это за игра, какая фантазия (одна фраза)? 2) Что игрок должен сделать первым? 3) Что изменилось в мире после его действий (было → стало, секунда)? 4) Какая цель видна сейчас, на сессию, на будущее? 5) В какой секунде новичок, скорее всего, растерялся или заскучал и почему? Не угадывай: если по кадрам не видно — пиши «не видно».

Ведущий сравнивает ответы с `docs/GAME_SKELETON.md` (колонки 01–06, 09–11).

## Критерии PASS
| Пункт | Порог |
|---|---|
| Загрузка до первого кадра игры | ≤ 5 с (веб), без меню перед действием |
| Фантазия угадана холодным взглядом | совпадает по смыслу с колонкой 01 |
| Первое действие | ≤ 10 с, угадано |
| Видимый результат в мире | ≤ 30 с, назван «было → стало» |
| Следующая цель | видна ≤ 60 с, названа хотя бы короткая |
| Весь цикл | пройден ≤ 120 с |
Каждый провал = задача в `docs/TASKS.md` с секундой и кадром. Отчёт: `docs/FIRST_MINUTE.md` проекта (дата, сборка, таблица, ответы холодного взгляда, решения).
