# Воронка игрока: события в игре и разбор после запуска

Где теряем игрока: **зашёл → понял, с чего начать → сделал действие → увидел результат → получил награду → увидел цель → вернулся**. После каждого запуска ищем самый большой обрыв и меняем геймплей, а не добавляем контент.

## События (контракт, одинаковый во всех играх)
Модуль `templates/funnel/funnel.ts` копируется в `src/funnel.ts`. В коде игры вызывается `funnel.mark(имя)` один раз за сессию на каждый шаг:
| Событие | Когда |
|---|---|
| `boot` | скрипт запущен (ставит модуль сам) |
| `first_frame` | первый кадр игры (не загрузчик) |
| `first_input` | первый ввод игрока |
| `first_action` | главное действие сделано первый раз |
| `first_result` | мир изменился от действия (было → стало) |
| `first_reward` | первая награда получена |
| `next_goal_seen` | показана следующая цель (камера/подсветка/открытие) |
| `loop_done` | первый полный цикл пройден |
| `goal_<имя>` | вехи средних целей (`goal_room2`, `goal_star1`) |
| `rewarded_offer` / `rewarded_watch` | показали предложение rewarded / досмотрели |
| `session_end` | уход со страницы (ставит модуль сам, с длиной сессии) |
| `return` | новая сессия при существующем сохранении (ставит модуль сам, с днём) |

Модуль хранит события в `window.__game.funnel` (для автотестов и первой минуты) и в localStorage (локальный дневник), а `funnel.onEvent` передаёт их в аналитику, если она есть (своя или площадки). Ничего не отправляется наружу, пока Alex не подключил получателя.

## Метрики площадок
- CrazyGames: в кабинете разработчика после запуска — playtime, конверсия в геймплей, ретеншн (смотреть там, цифры в `docs/LAUNCH.md`).
- Playgama, Яндекс: метрики их кабинетов.
- Roblox: CCU, D1/D7, средняя сессия, конверсия в покупки (Creator Dashboard).

## Разбор после запуска (`retro`, режим «воронка»)
1. Цифры кабинета + наш дневник → таблица шагов с долей дошедших.
2. Самый большой обрыв → вопросы: почему здесь? Понимает ли игрок, что делать дальше? Не стоит ли он, ожидая, пока ничего не происходит? Что покупают / за что смотрят рекламу чаще всего и почему?
3. Одна правка геймплея на самый большой обрыв → новая сборка → смотрим новую воронку.
4. Итог в `DesignLibrary/games/<наша-игра>.md` (наши игры тоже карточки) и, если урок общий, в `CONSTITUTION.md` или `LESSONS/`.
