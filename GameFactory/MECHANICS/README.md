# MECHANICS: готовые механики с тестами

Механика, которую уже «вымучили» в одной игре, записывается сюда, чтобы следующая игра собиралась быстрее и не повторяла ошибки. Каждая запись — рецепт + где лежит код + тест, который доказывает, что механика работает.

## Когда пополнять
Агент сам, без просьбы: механика принята Alex (проверка B/C или «механика ок») или на неё ушло больше двух итераций правок. Одна механика = один файл `<жанр>-<механика>.md` по шаблону [_TEMPLATE.md](_TEMPLATE.md), строка в индексе ниже.

## Как использовать
- План новой игры (шаг 6): для каждой механики скелета сначала ищем здесь (`grep -il '<слово>' MECHANICS/*.md`). Нашли — в плане «берём из MECHANICS/x, адаптируем параметры».
- Переносим код из проекта-источника (путь в записи) как копию, параметры — в конфиг геймфила.
- Тесты механики переносим вместе с кодом: `tools/mechanics.py` (шаблон `templates/autotest/lib/mechanics.py`).

## Тестирование механик
Тест механики = «настроить → сделать действие как игрок → проверить результат в состоянии игры за N секунд». Запуск: `npm run mechanics` (все) или `-- --only <имя>`. Тесты пишутся на `window.__game`, ждут состояние, а не время, и стартуют с безопасной точки (см. `LESSONS/testing.md`). Входят в смоук, если механика на ключевом пути.
