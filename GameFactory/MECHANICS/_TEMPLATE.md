# <Механика> (<жанр>)

**Что делает игрок:** одна фраза (ввод → что видит).
**Почему приятно:** отдача, звук, VFX, анимация, тайминги.
**Роли в цикле:** какие колонки скелета закрывает (04 действие, 05 результат, 12 своё растущее…).

## Параметры геймфила
| Параметр | Значение | Диапазон, который пробовали | Как ощущается |
|---|---|---|---|

## Код
- Проект-источник: `<папка игры>` · коммит `<hash>`
- Файлы: `src/...` (модуль), `src/config/feel.ts` (параметры)
- Зависимости: three / rapier / gsap / …
- Контракт с `window.__game`: какие поля и команды нужны тесту.

## Тест

```python
# tools/mechanics.py → MECHANICS
dict(name='<механика>', setup="<js: старт с безопасной точки>",

```
