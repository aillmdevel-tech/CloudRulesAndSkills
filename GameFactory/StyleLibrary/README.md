# StyleLibrary: визуальная библиотека вкуса Alex

Шаблоны графики, анимаций, VFX и UI по играм, которые нравятся Alex. Здесь только разбор стиля, чужих ассетов нет. Картинки взяты из публичных материалов Steam и нужны только как референс.

## Структура
- [TASTE.md](TASTE.md): общий вкус, что повторяется во всех играх.
- `genres/`: жанровые шаблоны.
  - [coop-chaos-fp.md](genres/coop-chaos-fp.md): кооп-хаос от первого лица.
  - [cartoon-movement-arcade.md](genres/cartoon-movement-arcade.md): мультяшная аркада с движением, линии Barji и Zoteling.
  - [horror.md](genres/horror.md): хоррор, ожидает разбора.
- `games/<игра>/CARD.md`: карточка игры (рендер, палитра hex, свет, камера, персонажи, анимация, VFX, UI, рецепт под Three.js) + `img/` (3 ключевых скрина, лист скриншотов, лист кадров трейлера с таймкодами).
- `data/summary.json`: метаданные Steam (теги, ссылки на скрины и трейлеры), `data/palettes.json`: палитры и средняя яркость/насыщенность.

## Как применять в новом проекте (порядок приоритетов)
1. **Явные слова Alex о графике в ТЗ — главное.** Библиотека их только дополняет.
2. Жанровый шаблон, ближайший к ТЗ (или полюс из TASTE.md).
3. Общий вкус из TASTE.md как дефолт там, где ТЗ молчит.

Шаги в `game-art-first`:
1. Прочитать README, TASTE и нужный шаблон жанра.
2. Найти на Steam 3–6 похожих игр под конкретное ТЗ (теги, «More like this»), выбирать по визуалу. Прислать Alex доску: ссылка, 1–2 скрина, почему подходит, что берём.
3. После согласования: стиль-борд в `docs/ART_SPEC.md` проекта со ссылками на карточки отсюда.

## Как добавлять новые игры
1. Alex присылает ссылки на Steam.
2. Скрипты в `tools/`: `fetch_steam.py` (метаданные и страницы), `grab_media.py` (скрины + кадры трейлера 1/с), `sheets.py` (листы и палитры). Нужен Python с Pillow и рабочий ffmpeg (если системный сломан, подойдёт `imageio-ffmpeg` во временном venv).
   Перенести в `games/<slug>/img/` 3 ключевых скрина и оба листа, затем удалить `_raw/` (временные кадры, около 25 МБ).
3. Просмотреть листы, написать `CARD.md` по шаблону существующих карточек. Каждый пункт помечать: [видно] или [гипотеза].
4. Отнести игру к жанру (или завести новый), обновить шаблон жанра и TASTE.md.
