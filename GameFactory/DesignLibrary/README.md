# DesignLibrary: база разборов игр (геймдизайн)

Всё, что увидено в чужих и своих играх: почему игрок начал, не вышел и вернулся. Отсюда растёт и проверяется `DESIGN/CONSTITUTION.md`. Пополняет скилл `game-design-library` по записям Alex (видео + голос + комментарии). Папка открывается в Obsidian как часть vault `WebAIGames`: ссылки `[[...]]`, таблица [INDEX.md](INDEX.md).

## Структура
| Что | Где |
|---|---|
| Как записывать игры | [RECORDING.md](RECORDING.md) |
| Карточки игр (по одной) | `games/<slug>.md` по шаблону [games/_TEMPLATE.md](games/_TEMPLATE.md) |
| Таблица всех игр | [INDEX.md](INDEX.md) — генерируется `python3 tools/index.py` |
| Паттерны (переносимые решения) | [PATTERNS.md](PATTERNS.md) |
| Хуки (почему начал / не вышел / вернулся) | [HOOKS.md](HOOKS.md) |
| Связки паттернов, проверенные в деле | [BUNDLES.md](BUNDLES.md) |
| GUI: HUD, иконки, окна | [GUI.md](GUI.md) |
| Механики по жанрам | `mechanics/<жанр>.md` |
| Разведка идей (Steam/Roblox/веб тренды) | `scout/` (снимки и отчёты `game-idea-scout`) |
| Входящие записи | `inbox/` — видео и заметки Alex, не в git |

## Правила
- Только увиденное: [видно] с таймкодом, [Alex] — слова Alex из озвучки/комментария, [вывод] — вывод агента. Чужих ассетов нет, только кадры для анализа.
- Каждая запись в PATTERNS/HOOKS/mechanics ссылается на игры-источники `[[games/slug]]`; карточка игры — на свои паттерны. Паттерн из 3+ игр помечается ★.
- Наши игры тоже карточки (`games/our-<slug>.md`) с цифрами воронки после запуска.
- Жанры — те же 11 папок, что в PromoLibrary (Выживание, Платформеры и побеги, Рыбалка и сбор животных, Симуляторы и тайкуны, Социальные и ролевые, Спорт и гонки, Стратегии, Физические песочницы, Хорроры, Экшен и PvP, Яйца и питомцы) + новые по мере надобности.
