# Паттерны: решения, которые переносятся

Формат: `## Название` → суть (одна фраза), где работает (жанр), игры `[[games/slug]]`, как сделать в вебе / Roblox, риски. ★ = 3+ игры.

## Мир меняется от действия
Каждое главное действие меняет мир, а не цифру (было грязно — стало чисто). Игры: Run a Motel (разбор интервью 2026-11). Веб: заметная смена материала/модели + VFX + звук. ★ — принцип конституции.

## Закрытое рядом = цель без подсказки
Следующая цель стоит в кадре закрытой: соседний номер, дверь, силуэт, ценник. Игры: Run a Motel. Веб: заблокированные объекты с ценой в мире, а не в меню.

## Новая потребность на 5-й минуте
Когда цикл освоен, у клиента/мира появляется новая потребность (кофе гостю) — новый подцикл. Игры: Run a Motel.

## Игра-очередь
Этапы, на каждом ждёшь своей очереди; нетерпение монетизируется (пропуск/ускорение). Игры: Become the Potato. Веб: rewarded «пропустить очередь», в ожидании — зрелище.
