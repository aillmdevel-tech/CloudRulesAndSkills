# Хуки: почему игрок начал, не вышел, вернулся

Формат: `## Хук` → тип (начал / не вышел / вернулся), механизм, игры `[[games/slug]]`. ★ = 3+ игры.

## Фантазия за три секунды (начал)
Обложка и первый кадр объясняют игру без чтения («свой старый мотель»). Игры: Run a Motel.

## Абсурдная фантазия-путь (начал)
Смешная невозможная роль и путь через этапы (картошка: выкопали → магазин → жарят → космос). Игры: Become the Potato.

## Большой масштаб виден с начала (вернулся)
С первых минут понятно, во что всё превратится (мотель → отель). Игры: Run a Motel.
