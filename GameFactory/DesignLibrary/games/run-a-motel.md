# Run a Motel!

**Фантазия одной фразой:** свой старый мотель, который ты превращаешь в отель.
**Главное действие:** убрать номер (было грязно — стало чисто).
**Почему жива / причина смерти:** весь цикл за 1–2 минуты, цели видны в мире без подсказок. ~178k Robux в день (по интервью); сделана за 3 дня.

## Первая минута (по секундам)
| с | Что видит игрок | Шаг формулы (1–5) | Alex сказал |
|---|---|---|---|
| 0–3 | свой старый мотель | 1 фантазия | — |
| ~10–30 | убирает номер, мир меняется | 2–3 | — |
| ~30–60 | обставляет номер мебелью (награда за уборку) | 4 | — |
| ~60–120 | гость платит, номер открыт | 5 | — |

## Цикл
убрать → обставить → гость платит → открыть следующий номер (~1–2 мин первый круг)

## Цели
- Сейчас: открыть соседний номер (стоит рядом закрытым).
- Сессия: мебель покруче, звёзды номеров.
- Неделя: весь мотель → отель.

## Хуки
- Начал: фантазия за 3 секунды.
- Не вышел: результат каждого действия виден в мире; на 5-й минуте новая потребность (кофе гостю).
- Вернулся бы: большой масштаб (отель) виден с начала.

## Что взять / чего избегать
- Взять: первая минута = весь цикл; цели закрытыми объектами рядом; новая потребность на 5-й минуте.
