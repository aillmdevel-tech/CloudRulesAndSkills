# Экономия токенов и перенос контекста между чатами

## Как это работает автоматически

1. **Хук `context_guard.py` (UserPromptSubmit)** — на каждом сообщении Alex читает размер текущего контекста из
   транскрипта сессии (последний ответ модели: input + cache read + cache creation).
   - ≥ **150k** — один раз: «держи PROJECT_STATE актуальным, в конце этапа — handoff».
   - ≥ **200k** или **2+ сжатия** — на каждом сообщении: ответить на запрос → скилл `chat-handoff` (сохранение) →
     предложить новый чат. Пороги: env `CONTEXT_GUARD_WARN` / `CONTEXT_GUARD_HARD`.
2. **Скилл `chat-handoff`** — сохраняет состояние в `docs/PROJECT_STATE.md` проекта (перезапись, не лог):
   правила Alex из чата, пути, команды, сделано, текущая задача, следующий шаг. Git — по правилам проекта.
3. **Новый чат** — в Claude Desktop Claude сам предлагает карточку новой сессии в той же папке с брифом
   «продолжи работу» (Alex только нажимает). В CLI/других клиентах — пишет: «открой новый чат в `<папка>`
   и напиши **продолжи работу**».
4. **Хук SessionStart (startup/resume/compact)** — напоминает прочитать актуальный блок
   `docs/PROJECT_STATE.md`; подробности открываются по задаче.
5. **Режим продолжения** (`продолжи работу`) — читает актуальный блок и обязательные правила + `git status/log` и делает «Следующий шаг»
   без повторного брифинга.

Итог: Alex ничего не отслеживает — Claude сам сохраняет состояние и зовёт в новый чат вовремя.

## Правила экономии (уже в CLAUDE.md)
- Один ведущий агент; подагенты/воркфлоу — только при явной выгоде (параллельная независимая работа, большой поиск).
- Не перечитывать весь проект ради мелкой правки; читать нужные участки файлов (offset/limit, grep).
- Краткий стиль ответов (`outputStyle: Concise`), без пересказа сделанного.
- Полные логи сборки и QA сохраняет `GameFactory/scripts/qa-brief.sh`. Для измерения окна и кэша используй `/context` и `/usage`.
- Скриншоты — уменьшенным масштабом; `read_page`/`get_page_text` вместо скриншотов, где хватает текста.
- Состояние проекта — в файлах (`PROJECT_STATE.md`, `DECISIONS.md`), а не в памяти чата.
- На `/compact` для преемственности не полагаться — резюме теряет детали.
- Перед большим новым этапом — новый чат, даже если порог не достигнут.
