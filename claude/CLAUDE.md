## Работа в проекте

- Для старта прочитай актуальный блок `docs/PROJECT_STATE.md`, затем нужные разделы по текущей задаче. При передаче сохрани факты, решения, проверку и следующий шаг в `PROJECT_STATE.md`; историю веди отдельно.
- Сохраняй фактический или явно заданный стек, принятый объём и исходные ассеты. Согласуй большой этап до реализации. Отмечай временные заглушки, гипотезы и пробелы захвата. Файлы владельца и исходники LevelCopier держи отдельно от рабочих копий.
- Перед «готово» выполни релевантные проверки проекта. Для игровой реализации сохраняй tsc, сборку, smoke, браузер, проверку управления, логики, коллизий, камеры и UI по затронутым сценариям. Визуал сверяй по снимкам с референсом.
- Команды сборки и QA запускай последовательно. Полный лог храни в файле, в чат возвращай итог и ограниченный фрагмент ошибки. Для видео и ассетов сначала получай короткую сводку скриптом. Один ведущий, отдельный агент только на независимую работу с явной выгодой.
- На этом Mac пользовательские Python/Node-команды запускай через `~/.local/bin/resource-run`. При занятых слотах жди освобождения.
- Работай в одном чате: автосжатие на 70% окна, новый чат (одна сессия «продолжи работу») только после 2 сжатий по подсказке context guard. Цепочки вложенных сессий не плоди. Большой новый этап начинай с краткой передачи. Детали экономии в `GameFactory/TOKEN_SAVING.md`.
- Для публикации, выгрузки файлов во внешние сервисы и удаления файлов владельца используй актуальное разрешение.

## Экономия контекста: MCP и скиллы

- PlayCanvas-скиллы (16 шт.) по умолчанию ВЫКЛЮЧЕНЫ и лежат в `~/.claude/spares/playcanvas`. Включать только если Alex прямо попросил PlayCanvas: `~/.local/bin/playcanvas-skills on` (нужен новый чат), после работы `playcanvas-skills off`. Сам не включай и не предлагай.
- MCP по умолчанию не используй. Вопросы, обсуждение, код, файлы, git, сборка, тесты решай Bash/Read/Edit без MCP. Не вызывай `session_connectors_status`, `ToolSearch` и MCP-инструменты «на всякий случай».
- Включай MCP только когда задача реально требует его, и только нужный:
  - Blender (`mcp__blender__*`): только живая работа со сценой/ассетами Blender.
  - Встроенный браузер (`mcp__Claude_Browser__*`): проверка запущенной игры/UI, сверка с референсом. Для обычного смоука сначала `game-autotest` (Playwright из терминала).
  - Claude in Chrome: только если Alex попросил его по имени.
  - Claude Docs (`mcp__1a59c906…`): только если Alex просит документ/doc. Коннектор по умолчанию выключен; включай `set_session_connector_enabled` и сообщи, что инструменты появятся в следующем ходу.
  - scheduled-tasks / CronCreate: только при просьбе про расписание или повторяющуюся задачу.
  - mcp-registry, ccd_sidebar/ccd_window/ccd_session: только по прямой просьбе.
- После завершения MCP-задачи, если коннектор был включён тобой, выключи его обратно (`enabled:false`), чтобы он не раздувал контекст следующих чатов.
- Deferred-инструменты загружай через ToolSearch одним запросом на нужный набор и только в момент необходимости.
