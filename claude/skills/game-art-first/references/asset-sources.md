# Where to look for ready things

Use WebSearch (standard, extended only for niche) — never from memory; check each link is alive and the licence is stated on the page.

## Free 3D / textures (prefer CC0)
- Kenney (kenney.nl) — CC0 low-poly kits, UI, icons.
- Quaternius (quaternius.com) — CC0 low-poly characters, environment, props.
- KayKit (kaylousberg.itch.io) — CC0 stylised kits.
- Poly Pizza, Poly Haven, ambientCG — CC0/CC-BY models, HDRIs, materials (also reachable through Blender MCP `search_assets`).
- Sketchfab (download-enabled, CC licences) — check licence per model.
- itch.io asset tags (low-poly, kit, modular) — licence per pack.

## GitHub / tools
Search by stack + genre: `three.js <genre> game`, `roblox obby/tycoon clone three.js`, `low poly town three.js`, Blender add-ons for modular/low-poly (Blender Market free, GitHub). Take: structure, shaders (toon/outline), level-editor ideas, not whole code without licence check (MIT/Apache/CC0).

## Web/Steam visual benchmarks
Find 3–5 games whose look fits the chosen adaptation option (browser games on CrazyGames/Poki/itch, Steam pages/screenshots). Give: link, what exactly is a good reference (palette, lighting, UI, camera), what to avoid. These are references only, not assets to copy.
