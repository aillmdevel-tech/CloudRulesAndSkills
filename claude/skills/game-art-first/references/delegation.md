# Delegation (one chat, quality first)

Model and effort are chosen by Alex; never switch them and never start sessions or new chats.

**Lead does itself:** reference analysis conclusions, gap questions, style decisions, map/location layout, key and hero models, camera, collisions/physics design, core mechanics and game feel, visual comparison verdicts, anything ambiguous.

**Subagent (inside this chat), only for bulky routine with a clear check:** video → frames and contact sheets, code/asset search, build/tsc/smoke/moderator runs (`game-autotest`), batch renames or material/pivot fixes by script, GLB exports by recipe, screenshot capture.

Brief = goal, files, done-criteria, verification command, «report in ≤10 lines». Files nobody else edits. The lead checks the result (diff or output).
Never delegate: design choices, reference interpretation, final approval.
