# Уроки из публикации Snack Toss Zoo / Hungry Zoo (чаты 21–26.11.2026)

## Что Alex хочет
- Один проход без напоминаний: он даёт иконку и обложку, дальше ты.
- Описание, трейлер и видео **одинаковые на обеих площадках**, если поле есть.
- Промо показывает весь цикл: прокачка → пришёл → бросил → выпало редкое (вау).
- Описание и теги адаптируй по 2–3 похожим успешным играм.
- Ответы короткие. В конце этапа: что сделано, **что осталось лично ему**, ссылка, чтобы поиграть с другого устройства.
- На модерацию только по его слову.

## Ошибки прошлых чатов → правило
| Что случилось | Правило |
|---|---|
| Локализацию вспомнили после заливки и промо | Локализация сразу после аудита |
| Alex узнавал, что от него нужно, вопросами | Список его действий выдавай сам, одним блоком |
| Не загрузили видео и описание на Playgama, хотя на CG были | После заливки сверяй поля двух площадок таблицей |
| 16, потом 8 скриншотов без необходимости | 4–5 на ориентацию |
| Обложки-кадры с HUD выглядели заглушками | В обложки только файлы Alex; нужный размер без потери качества. Мала — скажи сразу |
| Кнопки WATCH AD остались в сборке CG | Реклама и её кнопки выключены для Basic Launch |
| `npm run moderate` падал без playwright | Запускай через `pub moderate` |
| Отчёт одной площадки перезаписал другую | `pub moderate` хранит `publish/moderation/<площадка>.md` |
| Случайный `git checkout` откатил незакоммиченный отчёт | Без `git checkout/reset` в грязном дереве |

| Открыт не тот аккаунт Playgama | Сверь аккаунт до любых действий |
| Загрузка > 10 МБ не проходит | `pub prep-upload` и приёмы из справочников |
| Автоперевод Chrome стёр текст в полях | Портал только на английском |
