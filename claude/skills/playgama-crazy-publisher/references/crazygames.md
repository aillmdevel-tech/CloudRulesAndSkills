# CrazyGames: кабинет и требования

Проверено на Snack Toss Zoo 2026-11-22. Форма меняется: сверяй с тем, что видишь, и с docs.crazygames.com.

Кабинет: https://developer.crazygames.com · вход делает Alex в своём Chrome. Аккаунт бери из `PROJECT_STATE`, проверь, что черновик виден именно в нём.

## Шаги формы
1. **Before you submit** — 6 заявлений (загрузка < 20 с, проверено на телефоне, английский по умолчанию, понятно за минуту, прошёл кто-то другой, оригинальность и права). Галочки ставит Alex. Подсвети пункты, которые мы реально не проверили.
2. **Upload** — название (то же, что в игре: `<title>`, экран загрузки, обложки — CG сверяет), движок HTML5, сохранения через Data Module SDK, мобильные и ориентации, mute через SDK, файлы билда.
3. **QA Tool** — смотри панель: Loading Start/Stop, Gameplay Start/Stop, Mute, Get/Set Item зелёные, warnings 0. Ad и Banner серые в Basic Launch нормально. Load time завышается, когда Chrome занят (висящие вкладки preview, высокий load average Mac): закрой их и перезапусти QA, прежде чем чинить загрузку. Ссылка для Alex с телефона: `https://www.crazygames.com/preview/<gameId>?gameBuildId=<buildId>` (на странице есть Show QR Code) — всегда на текущий build.
4. **QA Results** — Yes/No и «I confirm» ставит Alex; дай ответ по каждому пункту с фактом. Результаты могут истечь после новой заливки: тогда снова «Go to QA».
5. **Details** открывается только после QA Results: категория, до 5 тегов, описание, управление, инструмент, обложки, видео.
6. **Submit** — две галочки (Terms, PEGI 12) и «Submit for approval»: только Alex или по его явному «да».

## Требования к файлам
| Поле | Формат |
|---|---|
| Обложки | 1920×1080, 800×1200, 800×800; из текста только название, без рамок и значков |
| Превью-видео | 16:9 и 2:3 (1920×1080, 1080×1620), без звука и текста, ≤ 50 МБ |
| Скриншоты | поля нет, не готовь |
| Билд | первая загрузка ≤ 50 МБ, всего ≤ 250 МБ, ≤ 1500 файлов; **zip не принимает**, только файлы с папками |

## Контент и сборка
- **В Basic Launch реклама запрещена.** Сборка CrazyGames без рекламы, кнопки WATCH AD скрыты.
- Английский обязателен и должен быть языком по умолчанию.
- В игру максимум за 1 клик, без своих кнопок fullscreen, кросс-промо, ссылок на сторы, внешнего входа.
- Текст читаем при DPR 1 и в iframe 907×510…1920×1080, мобильный 800×450.
- Без позиционирования «for kids», PEGI 12. Клоны и asset flip — причина отказа.
- С 23.11.2026 для игр Basic Launch учитывается CTR обложки (из нашего разбора в чате, перепроверь в доках при оформлении).

## Описание
Шаблон похожих успешных игр: вступление → «How to Play» с жирными подзаголовками → список фич → управление Desktop / Mobile. Без эмодзи. Тег Mobile площадка ставит сама.

## Заливка через Chrome (лимит file_upload ≈ 10 МБ)
`pub prep-upload --platform crazygames` раскладывает файлы билда на пачки ≤ 9 МБ с именами `a~~b~~c.ext` и `manifest.json`.
1. Перед новой заливкой «Delete all files» — только если Alex согласился заменить билд.
2. Загрузи пачки во вспомогательные `input[type=file]`, созданные на странице.
3. В странице пересоздай каждый `File` с `webkitRelativePath = 'game/' + путь` и отдай через DataTransfer в `webkitdirectory`-input, вызови `change`.
4. Сверь число файлов и вес в QA Tool с manifest.

Держи портал **на английском**: автоперевод Chrome стирал текст в полях описания.
