# Локализация

Языки Alex: **en (основной), ru, es, pt-BR, tr**. Отдельные ролики, обложки и скриншоты под языки не делаем, медиа на английском. Переводим все тексты игры.

## Откуда язык
Только из SDK через платформенный слой проекта, напрямую SDK из UI не трогай:
- сборка Playgama: `bridge.platform.language`;
- сборка CrazyGames: своя SDK, `SDK.user.systemInfo.locale`. Playgama Bridge в ней нет, если проект не подключил его явно. Проверь по коду;
- веб и dev: `navigator.language`.

Нормализация: `pt`, `pt-BR`, `pt_PT` → `pt-BR`; `es-*` → `es`; `tr-*` → `tr`; `ru-*` → `ru`; неизвестный → `en`. Шаблон: `templates/i18n.ts`. Параметр `?lang=xx` разрешён только для проверки и обязан работать в сборке, иначе `i18n-fit` не переключит язык.

## Порядок
1. `pub i18n-scan`: что уже есть и какие строки зашиты. Просмотри сам, скан эвристический. Не забудь canvas-текст, тосты, названия предметов и зверей, редкости, ошибки, тексты в данных, title.
2. Вынеси строки в словари. Без склейки предложений из кусков: параметры `{n}` и формы множественного числа (`Intl.PluralRules`, в ru три формы).
3. Переведи как игру, а не дословно. Имена собственные и название игры оставь. Числа и сокращения форматируй единообразно. Термины одинаковы во всех экранах.
4. `<html lang>` ставь при старте: от него зависит CSS `text-transform: uppercase`. Для JS — `toLocaleUpperCase(lang)`: в турецком `i → İ`, `ı → I`.
5. Шрифты: `pub i18n-fonts`. Нет кириллицы или `ğ ş ı İ ç ö ü ñ ã õ á é` — подбери той же фактуры шрифт с открытой лицензией, подключи по языку через `unicode-range` или `:lang()`. Подгружай только нужный язык, следи за весом.
6. Вылезание: `pub i18n-fit` в 16:9, портрете и мобильном. Чини адаптивно: перенос, авторазмер, запас ширины кнопки. Сокращай перевод только если вёрстка уже адаптивна.
7. Рантайм-аудит: `templates/i18n_audit.py` → `tools/i18n_audit.py` проекта (сценарий `play()` под игру). Он проходит игру на каждом языке и пишет весь показанный текст, DOM и canvas `fillText` (таблички, подписи над объектами, баннеры биомов, «1 in N», «tap to continue»), и помечает латиницу в ru/tr и совпадения с en в es/pt. Цель — 0 находок вне allow-list. Названия биомов, редкостей, мутаций тоже переводятся.
8. Посмотри листы глазами на каждом языке: главный экран, магазин, награды, настройки, туториал. Проверь и закрытые окна, скан видит только открытое.
9. Смоук обеих сборок.

## Готово, когда
- 0 зашитых пользовательских строк, ключи совпадают во всех 5 словарях;
- все глифы есть, вылезаний 0 на всех размерах;
- язык реально приходит из SDK в обеих сборках;
- в кабинетах указаны только эти языки.
