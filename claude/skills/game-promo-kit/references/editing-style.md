# Стиль монтажа и локализация

## Что делает ролик «сочным» (cartoon)
- **0–1 с — крючок.** Ролик открывается развязкой самого сильного момента (не позже 0,85 с от начала), крючок-вопрос выскакивает по словам. Без логотипа, заставки и затемнения. Первый кадр работает как обложка в ленте.
- **Ритм.** Клипы 1,2–2,4 с, пик на ~65% клипа, режем сразу после развязки. Итог 12–20 с. Склейки на долях такта: музыка Alex с `--bpm` или сгенерированный бит 120 BPM.
- **Переходы чередуются:** зум, свайп влево, белая вспышка, свайп вверх, плавный сдвиг. Каждый клип входит панч-зумом 1.16→1.0 и whoosh.
- **Пик:** разгон 1.25× → слоумо 0.5× (если игра отдала меньше 50 fps, кадры дорисовываются интерполяцией) + наезд камеры 1.0→1.1 + тряска + RGB-сдвиг 0,16 с + вспышка 0,05 с + «бум». Подпись события выскакивает в момент удара.
- **Порядок:** лучший момент первым, второй по силе — последним перед финалом, остальные в середине.
- **Цвет:** +16% насыщенности, +5% контраста. Тексты: толстая обводка, тень, pop-in с перелётом 124%, лёгкий поворот, слова крючка чередуют наклон.
- **Финал 1,8 с:** размытый стоп-кадр, вращающиеся лучи цвета акцента, логотип (`logo` в config) или название, пульсирующий CTA и звук награды.
- **Вертикаль из ландшафтного дубля** (`layout: stack`): игра крупной карточкой с белой рамкой на размытой копии себя, крючок в верхней полосе, подписи в нижней. Нативный вертикальный дубль всё равно лучше.
- **A/B:** список крючков в `texts.hook.<язык>` даёт по ролику на каждый, и каждый начинается с другого момента. Площадки рекламы сами выберут лучший.
## Чистое превью (clean)
Для hover-превью площадок: прямые склейки, без текста, звука, ускорений и вспышек; кадр начинается с обложки, если площадка просит.

## Что запрещено почти везде
Чужой геймплей, фейковые механики, кликбейт-UI («Play», стрелки-кнопки) в превью, логотипы сторов, рамки, чёрные полосы, курсор мыши, мыльная картинка.

## Локализация
- Все тексты — только в `promo/config.json` (`title`, `texts`, `captions`), на каждый язык из `languages`. В кадре нет «вшитого» текста игры на другом языке: снимай дубль в нужной локали игры, если UI виден (`--ui`).
- Скрипт сам уменьшает и переносит на 2 строки длинные переводы; всё равно проверь листы review для DE/TR/RU.
- Шрифт должен содержать алфавит: Arial Black — латиница и кириллица; для CJK/арабского укажи `font_file` с нужным шрифтом (OFL, с разрешения Alex скачать).
- Яндекс: слова на иконке, обложке, скриншотах и видео обязаны быть на языке локализации.
