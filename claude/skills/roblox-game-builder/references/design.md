### 1.1 Roblox Game Design Explained Like You're 5 Yrs Old — CRCcsYEB_6A
**Тезис:** топ-игры ниши — одна и та же механика «под капотом»; разложи их на блоки, возьми референс и поменяй ~20% в важных блоках (фантазия + уникальная механика).

**Фреймворк «дом из блоков»** (таблица по каждой игре ниши) [01:00–14:00]:
1. **Fantasy** — главный глагол игры (steal thing, raise thing, kick thing, escape with valuable, save animals). Фундамент вместе с unique mechanic [01:00, 05:00].
2. **Unique mechanic** — то, чем игра отличается (exploration, stock refresh, skill check, cleaning, feeding) [02:00–14:00].
3. **Core loop** — во всех: «leave base, get thing» (выйди с базы, принеси вещь) [02:00].
4. **RNG** — где происходит ролл: spawn table (мир спавнит), **pre-acquisition** (ролл виден до получения: пинаешь блок → ролл → несёшь) или **post-acquisition** (ролл после доставки на базу) [02:00–03:00].
5. **Level design** — linear (Escape Tsunami, Steal an Egg, Kick a Lucky Block, Surf and Rescue), radial/открытый (Ride a Pet), острова (Dig and Clean) [04:00, 06:00, 11:00].
6. **Tension** — момент «чуть не успел»: PvE (тебя гонят), PvPvE, time pressure (яйцо трескается через X сек) [04:00].
7. **Progression** — get faster / get stronger [05:00, 10:00].
8. **Collection** — get pets / collect treasure [05:00, 11:00].

**Процесс старта новой игры** [14:00–16:00]:
1. Пойми жанр/нишу.
2. Выбери референс-игру.
3. Разложи нишу по блокам выше.
4. Поменяй минимум 20% — в первую очередь fantasy и unique mechanic → хватает на 1–10K CCU.
5. Для 100K CCU нужны стэкнутые инновации (~40%: другой level design + tension + fantasy + механика), но «осмысленные, изученные».

**Примеры игр:**
- Ride a Pet — exploration (как Creatures of Sonaria) + simulator progression; radial level design; tension = time pressure (яйцо трескается), без монстра; RNG spawn table post-acquisition [02:00–04:00, 13:00, 16:00].
- Steal an Egg — fantasy «steal thing»; взял stock refresh каждые 5 мин из UI Grow a Garden и перенёс в мир; PvPvE (монстр + PvP) + FOMO/scarcity от рестока; linear [05:00–07:00].
- Escape Tsunami for Brainrots — «OG», один из первых с linear level design; **pressure valve level design**: бежишь → прячешься в «траншею» → бежишь (tension–release сжато); RNG pre-acquisition (видно в уровне, без ролла); PvE [07:00–09:00].
- Kick a Lucky Block — unique: skill check (тапни, пока заполняется полоска); progression «get stronger»; сильная live ops [09:00–10:00].
- Dig and Clean — unique: механика чистки; collection = сокровища; почти без tension [10:00–11:00, 13:00].
- Surf and Rescue — та же механика, что Dig and Clean, но fantasy «save animals» → другая (вероятно женская) аудитория + явная PvE tension (акула, скат). Автор предсказывает взлёт [11:00–13:00].
- Raise an Anomaly (игра автора) — от Steal an Egg поменяли fantasy (raise вместо steal) и добавили feeding; привлекло девочек, не игравших в Steal an Egg [14:00–15:00].

**Цифры:** 20% изменений → 1–5K, «может 10K» CCU [15:00–16:00]; Ride a Pet ~40% изменений → путь к 100K [16:00].
