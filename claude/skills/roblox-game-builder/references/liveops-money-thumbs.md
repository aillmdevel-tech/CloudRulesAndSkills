### 1.2 Roblox Game Monetization Explained Like You're 5 — zoz3PSMqets
**Тезис:** лучшие продукты — consumable dev products, снимающие реальную боль игрока; больше путей покупки и размещение в местах трафика; проверять влияние на все метрики, не только Robux.

Контекст: игра (вдохновлена Oil Empire, партнёр David) с 1K CCU, run rate ~$6K/мес → CCU ×2+, выручка ×3, run rate ~$15K/мес [00:00] (в начале «175k за 72 ч», вероятно Robux [вывод]).

**Процедура:**
1. Посмотреть данные: top products по продажам desc [01:00]. Бестселлер «+10 speed» → добавить «+30 speed» и «+100 speed для китов», дороже → новый бестселлер [01:00].
2. Наблюдать поведение в игре: игра активная, но многие AFK [01:00–02:00]. Не добавлять auto-collect game pass — сломает экономику [02:00].
3. AFK-игроков грабили в PvP (биты, кража «data» с серверов, как в Steal a Brainrot / Oil Empire) + подтверждение в Audience feedback («устал, что меня грабят») [02:00–03:00].
4. Сначала бесплатная механика: base lock каждые ~60 с (взята из другой игры жанра) [03:00]; затем dev product «lock base for 24 hours» → топ-селлер за 1–2 дня [04:00].
5. Consumables > game passes (как CPG в e-com) — качают метрику 7-day spend days per user (Home Recs: число уникальных дней трат за 7 дней) [04:00–05:00].
6. Конкурентный анализ: в Sell Lemons «2x offline earnings» — consumable; изначально планировали game pass → сделали dev product [05:00–06:00]. Каждый новый consumable, снимающий крупную фрикцию, становится бестселлером [06:00].
7. Purchase pathways для cash [06:00–09:00]: (1) кнопка Shop в HUD; (2) иконка «+» рядом со счётчиком cash → открывает cash shop; (3) при «not enough money» — 1-й и 2-й раз только ошибка, на 3-й раз автоматически открывается cash shop; лимит 3–5 раз за сессию. Консенсус девов: сразу открывать магазин при первой нехватке — раздражает и бьёт playtime. До этого cash почти не продавался.
8. Placement: физические dev products ставить в точках с наибольшим трафиком (POI). Поменял местами: платный 24h lock у входа в базу, бесплатный — дальше [10:00–11:00].
9. Тайминг промпта: 2x offline earnings предлагается в момент, когда игрок наступает на парт сбора офлайн-дохода, 19 Robux [13:00].

**Продукты и «боль» [11:00–14:00]:**

| +10/+30/+100 speed | боль усилия, не хочу грайндить | dev product |
| 1 bill money (cash pack) | боль усилия; цена не должна ломать экономику (не 9 Robux) | dev product |
